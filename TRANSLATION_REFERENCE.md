## PLURALIZATION HELPERS

For Russian pluralization, use this pattern:

```tsx
import { formatCount } from '@/lib/utils/i18n';

// Replace:
`${count} bike${count !== 1 ? 's' : ''}`

// With:
formatCount(count, 'велосипед', 'велосипеда', 'велосипедов')
```

Common plurals:
- bike → велосипед, велосипеда, велосипедов
- courier → курьер, курьера, курьеров
- assignment → назначение, назначения, назначений
- deduction → удержание, удержания, удержаний
- entry/entries → запись, записи, записей
- period → период, периода, периодов
- day → день, дня, дней
- week → неделя, недели, недель
- month → месяц, месяца, месяцев

## QUICK BATCH REPLACE ORDER

1. Replace all button labels first (Add, Edit, Delete, etc.)
2. Replace form field labels (Name, Description, etc.)
3. Replace status messages (Success, Error, Loading)
4. Replace empty states and validation messages
5. Fix pluralization with formatCount helper
6. Test UI for layout issues
